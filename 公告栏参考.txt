# 📢 公告栏系统

一个简单而美观的公告栏展示系统，使用React和Supabase构建！

## ✨ 功能特点

- 🎨 现代化UI设计，响应式布局
- 📱 支持移动端和桌面端
- 🔄 实时数据加载和错误处理
- 🏷️ 优先级标签系统（高/中/低）
- 📅 时间格式化显示
- 👤 发布人信息展示
- ��️ 支持多图附件显示（九宫格布局）
- 🔍 图片点击放大预览功能
- ⌨️ 键盘导航支持（方向键、Tab、Enter、Escape）
- 🎭 流畅的动画效果和过渡
- 📜 可展开/收起的公告列表
- 🎯 自动滚动到选中项

## 🎯 使用说明

### 公告栏功能
1. 确保Supabase数据库已创建并包含announcements表
2. 在表中插入一些测试数据（可包含img_url字段的图片链接数组）
3. 启动应用查看效果
4. 点击公告项查看详情，多张图片将以九宫格形式显示
5. 点击任意图片可放大预览

### 图片数据格式示例

```json
{
  "img_url": [
    "https://oss.sprb.love/sprb_cover.webp",
    "https://oss.sprb.love/sprb_cover2.webp"
  ]
}
```

或者使用逗号分隔的字符串：
```json
{
  "img_url": "https://oss.sprb.love/sprb_cover.webp, https://oss.sprb.love/sprb_cover2.webp"
}
```

## 🗄️ 数据库结构

系统使用Supabase数据库，需要创建以下表结构：

```sql
CREATE TABLE announcements (
  id SERIAL PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  author VARCHAR(100) NOT NULL,
  is_published BOOLEAN DEFAULT true,
  priority VARCHAR(20) DEFAULT 'low' CHECK (priority IN ('high', 'medium', 'low')),
  img_url TEXT
);
```

### 字段说明

- `id`: 公告唯一标识符
- `title`: 公告标题
- `content`: 公告内容
- `created_at`: 创建时间
- `author`: 发布人
- `is_published`: 是否发布（true/false）
- `priority`: 优先级（high/medium/low）
- `img_url`: 图片URL数组（支持JSON格式或逗号分隔的字符串，最多显示前9张）

### 状态管理策略

#### 数据流设计
```
Supabase API → fetchAnnouncements() → setAnnouncements() → 组件渲染
```

#### 状态更新模式
```javascript
// 异步数据获取模式
const fetchAnnouncements = async () => {
  try {
    setLoading(true)
    const { data, error } = await supabase
      .from('announcements')
      .select('*')
      .eq('is_published', true)
      .order('created_at', { ascending: false })
    
    if (error) throw error
    setAnnouncements(data || [])
  } catch (err) {
    setError(err.message)
  } finally {
    setLoading(false)
  }
}
```

### 键盘导航系统

#### 事件监听器
```javascript
useEffect(() => {
  const handleKeyDown = (e) => {
    if (e.key === "ArrowDown" || (e.key === "Tab" && !e.shiftKey)) {
      e.preventDefault()
      setKeyboardNav(true)
      setSelectedIndex((prev) => Math.min(prev + 1, announcements.length - 1))
    } else if (e.key === "ArrowUp" || (e.key === "Tab" && e.shiftKey)) {
      e.preventDefault()
      setKeyboardNav(true)
      setSelectedIndex((prev) => Math.max(prev - 1, 0))
    } else if (e.key === "Enter") {
      if (selectedIndex >= 0 && selectedIndex < announcements.length) {
        e.preventDefault()
        handleAnnouncementSelect(announcements[selectedIndex], selectedIndex)
      }
    } else if (e.key === "Escape") {
      closeModal()
    }
  }

  window.addEventListener("keydown", handleKeyDown)
  return () => window.removeEventListener("keydown", handleKeyDown)
}, [announcements, selectedIndex])
```

#### 自动滚动实现
```javascript
useEffect(() => {
  if (!keyboardNav || selectedIndex < 0 || !listRef.current) return
  
  const container = listRef.current
  const selectedItem = container.querySelector(`[data-index="${selectedIndex}"]`)
  
  if (selectedItem) {
    const extraMargin = 50
    const containerScrollTop = container.scrollTop
    const containerHeight = container.clientHeight
    const itemTop = selectedItem.offsetTop
    const itemBottom = itemTop + selectedItem.offsetHeight
    
    // 智能滚动逻辑
    if (itemTop < containerScrollTop + extraMargin) {
      container.scrollTo({ top: itemTop - extraMargin, behavior: "smooth" })
    } else if (itemBottom > containerScrollTop + containerHeight - extraMargin) {
      container.scrollTo({
        top: itemBottom - containerHeight + extraMargin,
        behavior: "smooth",
      })
    }
  }
  setKeyboardNav(false)
}, [selectedIndex, keyboardNav])
```

### 图片处理系统

#### 多格式支持
```javascript
// 智能图片URL解析
const parseImageUrls = (imgUrl) => {
  let imageUrls = [];
  try {
    if (typeof imgUrl === 'string') {
      imageUrls = JSON.parse(imgUrl);
    } else if (Array.isArray(imgUrl)) {
      imageUrls = imgUrl;
    }
  } catch (e) {
    if (typeof imgUrl === 'string') {
      imageUrls = imgUrl.split(',').map(url => url.trim());
    }
  }
  return imageUrls;
}
```
