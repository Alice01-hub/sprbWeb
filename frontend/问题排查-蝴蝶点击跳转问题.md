# 🐛 问题排查：蝴蝶点击跳转问题

## 问题描述
用户反馈：点击蝴蝶时会发生跳转，而不是打开信息框。

## 代码检查结果
✅ 代码逻辑正确：
- `MemoryButterfly` 的 `onClick` 正确调用 `handleButterflyClick`
- `handleButterflyClick` 只设置 `selectedMemory` 状态
- `selectedMemory` 变化触发 `MemoryCard` 渲染
- `MemoryCard` 中的链接需要手动点击才会跳转

## 可能的原因

### 1. 浏览器缓存问题 ⭐ 最可能
**现象**：浏览器使用了旧版本的代码

**解决方法**：
```
方法1：强制刷新
- Windows: Ctrl + Shift + R
- Mac: Cmd + Shift + R

方法2：清除缓存
1. 按F12打开开发者工具
2. 右键点击浏览器刷新按钮
3. 选择"清空缓存并硬性重新加载"

方法3：禁用缓存
1. F12打开开发者工具
2. Network标签
3. 勾选"Disable cache"
4. 刷新页面
```

### 2. 开发服务器问题
**现象**：Vite热重载失效

**解决方法**：
```powershell
# 停止开发服务器（Ctrl+C）
# 然后重新启动
cd frontend
npm run dev
```

### 3. 组件状态问题
**现象**：React状态未正确更新

**排查方法**：
1. 打开浏览器开发者工具（F12）
2. 切换到Console标签
3. 点击蝴蝶
4. 查看是否输出：`🦋 点击蝴蝶: [蝴蝶标题]`

**如果没有输出**：
- 说明点击事件未触发
- 可能被其他元素遮挡

**如果有输出但MemoryCard未打开**：
- React组件渲染问题
- 检查React DevTools

### 4. 数据库数据问题
**现象**：某些蝴蝶数据可能导致异常

**排查SQL**：
```sql
-- 检查是否有蝴蝶的web_url包含javascript:
SELECT * FROM memories 
WHERE web_url LIKE 'javascript:%' 
OR web_url LIKE 'data:%';

-- 如果有，删除或修正
UPDATE memories 
SET web_url = NULL 
WHERE web_url LIKE 'javascript:%';
```

### 5. 其他组件干扰
**现象**：其他全局组件可能拦截点击事件

**排查方法**：
检查以下组件是否有全局点击事件监听：
- `ButterflyCustomCursor.tsx`
- `MusicPlayer.tsx`
- `App.tsx`

## 预期行为

### 正确流程：
```
用户点击蝴蝶
    ↓
触发 ButterflyContainer onClick
    ↓
调用 handleButterflyClick(memory)
    ↓
Console输出: 🦋 点击蝴蝶: [标题]
    ↓
setSelectedMemory(memory)
    ↓
React重新渲染
    ↓
MemoryCard组件渲染（因为selectedMemory不为null）
    ↓
显示带有夜空主题的信息框
    ↓
用户在信息框中点击链接
    ↓
新标签页打开链接
```

### 错误流程（用户反馈）：
```
用户点击蝴蝶
    ↓
直接发生页面跳转 ❌
```
