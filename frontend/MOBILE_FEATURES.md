# 移动端地图缩放和拖拽功能

## 功能概述

为了提升移动端用户体验，我们为网站的地图功能添加了双指缩放和单指拖拽支持。现在移动端用户可以更方便地查看地图信息。

## 新增组件

### 1. ZoomableIslandMap
- **用途**: 岛屿页面的可缩放地图组件
- **位置**: `frontend/src/components/ZoomableIslandMap.tsx`
- **功能**: 
  - 双指缩放 (0.8x - 4x)
  - 单指拖拽
  - 智能设备检测
  - 移动端优化的图标点击区域
  - 缩放控制按钮

### 2. ZoomableOverviewMap
- **用途**: 打卡页面的可缩放总览地图组件
- **位置**: `frontend/src/components/ZoomableOverviewMap.tsx`
- **功能**:
  - 双指缩放 (0.8x - 4x)
  - 单指拖拽
  - 响应式高度调整
  - 移动端提示信息

### 3. ZoomableMapContainer
- **用途**: 通用的可缩放地图容器组件
- **位置**: `frontend/src/components/ZoomableMapContainer.tsx`
- **功能**:
  - 基于 MapConfig 的配置系统
  - 与现有 MapIcon 组件兼容

## 技术特性

### 设备检测
- 自动检测移动端、平板和桌面设备
- 基于用户代理、触摸支持和屏幕尺寸的智能判断
- 响应式配置调整

### 移动端优化
- **触摸区域**: 移动端图标点击区域增大至 44px × 44px
- **缩放范围**: 移动端支持 0.8x - 4x 缩放
- **初始缩放**: 移动端默认 0.9x 缩放以适应屏幕
- **禁用滚轮**: 移动端禁用滚轮缩放，避免冲突

### 用户体验
- **操作提示**: 移动端显示 3 秒操作提示
- **缩放控制**: 右下角提供 +、-、⌂ 缩放按钮
- **平滑动画**: 所有交互都有流畅的动画效果
- **防误触**: 智能的触摸事件处理

## 使用方法

### 移动端操作
1. **双指缩放**: 两个手指在地图上捏合或张开进行缩放
2. **单指拖拽**: 单个手指在地图上滑动进行拖拽
3. **点击图标**: 点击地图上的图标查看详情
4. **缩放按钮**: 使用右下角的按钮进行精确控制

### 桌面端操作
1. **鼠标滚轮**: 滚轮缩放地图
2. **鼠标拖拽**: 按住鼠标左键拖拽地图
3. **双击缩放**: 双击地图进行缩放
4. **图标悬停**: 鼠标悬停显示详细信息

## 配置选项

```typescript
interface ZoomableMapProps {
  enableZoom?: boolean;     // 是否启用缩放 (默认: true)
  enablePan?: boolean;      // 是否启用拖拽 (默认: true)
  minScale?: number;        // 最小缩放比例 (默认: 0.5)
  maxScale?: number;        // 最大缩放比例 (默认: 3)
  initialScale?: number;    // 初始缩放比例 (默认: 1)
}
```
