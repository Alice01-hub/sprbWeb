# 🦋 神域蝴蝶功能 - 5分钟快速上手

## 🚀 快速开始

### 第一步：创建数据库表

1. 登录 [Supabase Dashboard](https://supabase.com/dashboard)
2. 选择你的项目
3. 进入 **SQL Editor**
4. 复制并执行 `backend/create_memories_table.sql` 中的SQL代码
5. 执行完成后，会自动创建表并插入10条测试数据

### 第二步：启动项目

```bash
# 启动前端
cd frontend
npm run dev
```

### 第三步：查看效果

1. 打开浏览器，访问前端地址（通常是 http://localhost:5173）
2. 进入"神域"页面
3. 点击"切换场景"按钮
4. 你会看到3-5只蝴蝶在场景中飞舞！

## 📝 添加新蝴蝶

### 方法1: 在Supabase Dashboard中添加（推荐）

1. 进入 **Table Editor**
2. 选择 `memories` 表
3. 点击 **Insert row**
4. 填写以下字段：

   | 字段 | 说明 | 示例 | 必填 |
   |------|------|------|------|
   | user_name | 作者名称 | "旅行者" | ✅ |
   | title | 标题 | "夏日回忆" | ✅ |
   | content | 内容 | "在鸟白岛的夏天..." | ❌ |
   | image_url | 图片链接 | "https://..." | ❌ |
   | audio_url | 音频链接 | "https://..." | ❌ |
   | web_url | 跳转链接 | "https://..." | ❌ |
   | weight | 权重(1-5) | 3 | ✅ |
   | is_published | 是否发布 | true | ✅ |

5. 点击 **Save**

### 方法2: 使用SQL批量添加

在 **SQL Editor** 中执行：

```sql
INSERT INTO memories (user_name, title, content, weight, is_published) VALUES
('你的名字', '蝴蝶标题', '这是一段美好的回忆内容...', 3, true);
```

## 🔧 常见问题

### Q: 为什么看不到蝴蝶？
A: 检查以下几点：
1. 数据库中是否有 `is_published = true` 的记录
2. 浏览器控制台是否有错误
3. 刷新页面或点击"切换场景"

### Q: 如何调整蝴蝶数量？
A: 在 `memoryService.ts` 中修改：
```typescript
const actualCount = count || (Math.floor(Math.random() * 3) + 3)
// 修改为：
const actualCount = count || (Math.floor(Math.random() * 5) + 5)  // 5-9只
```

### Q: 如何更换蝴蝶图片？
A: 在 `MemoryButterfly.tsx` 中修改 `BUTTERFLY_IMAGES` 数组

### Q: 如何隐藏某只蝴蝶？
A: 在Supabase中将该记录的 `is_published` 改为 `false`

## 💡 使用技巧

### 1. 权重分配建议
建议保持以下比例：
- Weight 5: 10%（精选内容）
- Weight 4: 20%（重要内容）
- Weight 3: 40%（普通内容）
- Weight 2: 20%（次要内容）
- Weight 1: 10%（装饰蝴蝶）

### 2. 内容策划
- 定期更新蝴蝶内容，保持新鲜感
- 根据季节或活动调整主题
- 结合游戏剧情增强代入感
- 鼓励用户投稿优质内容

### 3. 视觉搭配
- 图文结合效果最佳
- 音频可增强沉浸感
- 链接可延展阅读深度
- 适当留白，不要全是文字

## 📊 数据管理SQL

### 查看所有已发布的蝴蝶
```sql
SELECT * FROM memories 
WHERE is_published = true 
ORDER BY weight DESC, created_at DESC;
```

### 统计蝴蝶数量
```sql
SELECT 
  COUNT(*) as total,
  SUM(CASE WHEN is_published = true THEN 1 ELSE 0 END) as published
FROM memories;
```

### 批量修改权重
```sql
UPDATE memories 
SET weight = 4 
WHERE title LIKE '%重要%';
```

### 删除测试数据
```sql
DELETE FROM memories 
WHERE user_name LIKE '旅行者%';
```

## 🎯 最佳实践

### ✅ 推荐做法
- 每只蝴蝶都有意义的内容
- 标题简短有力（5-10字）
- 内容控制在50-500字
- 使用高质量图片
- 定期审核和更新内容

- 纯广告内容
- 无关主题的内容
- 过长的文字（影响阅读）
- 损坏的图片或音频链接
- 无效的跳转链接
