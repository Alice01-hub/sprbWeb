# 公告栏格式使用说明

## 概述

公告栏现在支持多种文本格式，让您能够创建更加美观和结构化的公告内容。

## 支持的格式

### 1. 段落和换行

**换行符** (`\n`)
- 在文本中按 Enter 键换行
- 自动创建新的段落

**示例**:
```
第一段内容
第二段内容
第三段内容
```

### 2. 标题格式

**一级标题** (`# 标题`)
- 使用 `# ` 开头（注意空格）
- 显示为大号加粗标题，带有下划线

**二级标题** (`## 标题`)
- 使用 `## ` 开头
- 显示为中等大小的标题

**示例**:
```
# 重要通知
## 更新内容
这是具体的更新说明
```

### 3. 列表格式

**列表项** (`- 项目`)
- 使用 `- ` 开头（注意空格）
- 自动添加项目符号

**示例**:
```
- 第一项内容
- 第二项内容
- 第三项内容
```

### 4. 缩进格式

**缩进** (空格)
- 在行首添加两个或更多空格
- 自动创建缩进效果，带有左边框

**示例**:
```
主要内容
  缩进内容1
  缩进内容2
    更深层缩进
```

### 5. 文本样式

**加粗** (`**文字**`)
- 使用 `**文字**` 格式
- 显示为粗体文字

**斜体** (`*文字*`)
- 使用 `*文字*` 格式
- 显示为斜体文字

**代码** (`` `代码` ``)
- 使用 `` `代码` `` 格式
- 显示为代码块样式

**示例**:
```
这是**重要**的文字
这是*强调*的文字
这是`代码`示例
```

### 6. 链接格式

**链接** (`[文字](链接)`)
- 使用 `[显示文字](链接地址)` 格式
- 自动创建可点击的链接

**示例**:
```
点击[这里](https://example.com)访问网站
```

### 7. 表情符号

**表情代码**
- 使用 `:代码:` 格式
- 自动转换为对应的表情符号

**支持的代码**:
- `:smile:` → 😊
- `:heart:` → ❤️
- `:star:` → ⭐
- `:warning:` → ⚠️
- `:info:` → ℹ️
- `:check:` → ✅
- `:cross:` → ❌
- `:arrow:` → ➡️
- `:fire:` → 🔥
- `:sparkles:` → ✨

## 完整示例

```
# 网站更新通知

## 新增功能
- 公告栏格式支持
- 文本样式美化
- 响应式设计优化

## 使用方法
  1. 使用 **Markdown** 语法
  2. 支持 *斜体* 和 `代码` 格式
  3. 可以添加表情 :smile:

## 注意事项
  请合理使用格式，避免过度装饰影响阅读体验。

更多信息请访问[帮助页面](https://help.example.com)
```

## 格式优先级

格式处理的优先级如下：
1. 换行符分割
2. 标题识别
3. 列表识别
4. 缩进识别
5. 行内格式处理

## 注意事项

1. **安全性**: 所有HTML标签都会被安全过滤，只允许安全的格式标签
2. **兼容性**: 支持现有的纯文本公告，无需修改
3. **性能**: 格式处理在客户端进行，不影响服务器性能
4. **响应式**: 所有格式都支持移动端显示
